# Glossary

- **Backdrop:** Window background effect supplied by a UI framework or Windows composition.
- **Event-driven:** Reacting to state-change events rather than repeatedly checking state.
- **GSMTC:** Global System Media Transport Controls, an API for supported Windows media sessions.
- **Idle CPU:** CPU use while the app is open without meaningful interaction or state changes.
- **Island:** Compact floating UI near the top-center of a display.
- **MVVM:** Model-View-ViewModel, separating UI from presentation state and commands.
- **Transport controls:** Previous, play/pause, and next commands exposed by a media player.
