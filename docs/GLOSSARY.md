# Glossary

- **Acrylic:** Windows visual material that can blend/translucently blur background content when supported.
- **Backdrop:** Window background effect supplied by a UI framework or Windows composition.
- **Core Audio:** Windows APIs for inspecting and controlling audio endpoints and volume.
- **Event-driven:** Reacting to state-change events rather than repeatedly checking state.
- **GSMTC:** Global System Media Transport Controls, an API for supported Windows media sessions.
- **Idle CPU:** CPU use while the app is open without meaningful interaction or state changes.
- **Island:** Compact floating UI near the top-center of a display.
- **MVVM:** Model-View-ViewModel, separating UI from presentation state and commands.
- **Notification preview:** Limited notification representation, potentially containing sensitive text.
- **Topmost window:** Window placed above ordinary non-topmost windows; not guaranteed above all full-screen or secure desktop surfaces.
- **Working set:** Physical memory currently resident for a process; one of several useful memory metrics.
